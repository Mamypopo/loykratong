# ลอยกระทงด้วยกัน

เว็บลอยกระทงออนไลน์สำหรับคนในองค์กร ใส่ชื่อ เขียนคำอธิษฐาน แล้วลอยกระทงไปพร้อมกัน
กระทงของทุกคนจะลอยผ่านในจอของเพื่อนๆ และบนจอใหญ่ในงาน

- หน้าหลัก: `https://<โดเมนของคุณ>/` ส่งลิงก์นี้ให้ทุกคน
- จอใหญ่: `https://<โดเมนของคุณ>/?screen=1` เปิดบนเครื่องที่ต่อโปรเจคเตอร์ มี QR code ให้สแกนเข้ามาลอยได้ทันที
- **🧺 กระทงของฉัน**: ชั้นวางกระทงที่ทำไว้ (สูงสุด 12 ใบ เก็บในเครื่องนี้) เลือกใบที่จะลอย แก้ ลบ และดูได้ว่าแต่ละใบลอยไปกี่ครั้ง
  กด **ลอยกระทงของฉัน** เพื่อลอยใบที่เลือก (ไม่พิมพ์คำอธิษฐานก็ได้)
- **🏛 กระทงทุกคน**: ห้องจัดแสดงกระทงที่ทุกคนทำแล้วลอยไป แตะเพื่อหมุนดูแบบ 3 มิติ และให้หัวใจได้คนละ 1 ดวงต่อใบ
- **โต๊ะทำกระทง**: ทำกระทงใหม่หรือแก้ใบเดิมบนโต๊ะไม้ที่มีต้นกล้วยวางอยู่
  - **ตัดต้นกล้วยเอง**: เลื่อนมีดแล้วตัด ตัดหนาก็ได้ฐานสูง หรือจะใช้ฐานสำเร็จ 6 แบบก็ได้
  - **ตัดกลีบใบตอง**: ลากนิ้ววาดรูปกลีบ เลือกสีใบตองและจำนวนกลีบได้
  - **ติดของตรงไหนก็ได้**: เทียน ธูป ดอกไม้ เหรียญ เป็ดยาง ไข่ดาว หมวกปาร์ตี้ ฯลฯ แตะเพื่อติด ลากเพื่อย้าย หมุน ย่อ ขยาย ยก หรือลบได้
  - **วาดเอง**: วาดอะไรก็ได้ (สูงสุด 3 ภาพ) แล้วปักเป็นสติกเกอร์บนกระทง
  - **รูปของฉัน**: ปักรูปตัวเองเป็นโพลารอยด์
  - เพื่อนและจอใหญ่จะเห็นกระทงหน้าตาเดียวกับที่ทำทุกอย่าง เพราะระบบส่ง "สูตรกระทง" ไป แล้วแต่ละเครื่องประกอบเป็นสามมิติเอง

## ขึ้นเว็บบน Vercel (ครั้งแรก ประมาณ 10 นาที)

1. **Deploy** เลือกทางใดทางหนึ่ง
   - ใช้คำสั่ง: เปิด terminal ในโฟลเดอร์นี้ แล้วพิมพ์ `npx vercel --prod` จากนั้นตอบคำถามตามค่าเริ่มต้น (กด Enter)
   - ใช้ GitHub: push โฟลเดอร์นี้ขึ้น GitHub แล้วกด **Add New → Project** ใน Vercel เพื่อเลือก repo ไม่ต้องตั้งค่าอะไรเพิ่ม
2. **เพิ่มที่เก็บคำอธิษฐาน**: เข้าโปรเจคใน Vercel แล้วไปที่ **Storage → Create Database → Upstash → Upstash for Redis** เลือกแผน **Free** แล้วกด Connect กับโปรเจคนี้
   Vercel จะใส่ค่า `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้อัตโนมัติ
3. **Deploy ใหม่**: พิมพ์ `npx vercel --prod` อีกครั้ง
4. **เอาลิงก์ที่จะแจก**: ใช้โดเมน production ที่ Vercel → Project → **Domains** เช่น `ชื่อโปรเจค.vercel.app`
   **อย่าแจกลิงก์ยาวๆ ที่มีรหัสสุ่ม** ลิงก์แบบนั้นเป็นลิงก์ preview ซึ่งต้องล็อกอิน Vercel ก่อนถึงจะเปิดได้
   ให้ลองเปิดลิงก์ที่จะแจกในหน้าต่างไม่ระบุตัวตน (incognito) ถ้าเปิดได้โดยไม่ต้องล็อกอิน ก็ใช้ลิงก์นั้นได้เลย
5. **ทดสอบ**: เปิดหน้าหลักบนมือถือ ลอยกระทงหนึ่งอัน แล้วดูว่ากระทงขึ้นบนจอใหญ่ภายในไม่กี่วินาที
6. **ระหว่างวันงาน**: ดูที่ Vercel → **Usage** ช่วงเที่ยงว่าโควต้ายังเหลือ

ถ้ายังไม่ได้ทำข้อ 2 เว็บก็ยังเปิดได้ แต่ละคนจะลอยกระทงได้ในจอตัวเอง แต่จะไม่เห็นกระทงของเพื่อน

## ดูแลระหว่างงาน

- **เพิ่มหรือลบคำต้องห้าม**: แก้ไฟล์ [public/filter.js](public/filter.js) แล้ว deploy ใหม่
  - `SUBSTRING_WORDS` บล็อกเมื่อคำนี้อยู่ส่วนไหนของข้อความก็ได้ ระวังคำที่ซ้อนอยู่ในคำปกติ เช่น "หี" อยู่ใน "หีบ"
  - `TOKEN_WORDS` บล็อกเฉพาะเมื่อเป็นคำเดี่ยวๆ ใช้กับภาษาอังกฤษ
  - ลิงก์ เบอร์โทร และ @ชื่อคน ถูกบล็อกเสมอ
- **คำอธิษฐานเก็บไว้แค่ 300 อันล่าสุด** และหายเองใน 7 วันหลังกระทงอันสุดท้าย
- **ส่งได้คนละ 1 กระทงต่อ 4 วินาที** นับแยกตามเครื่อง คนทั้งออฟฟิศที่ใช้เน็ตเดียวกันจึงส่งพร้อมกันได้ (เพดานรวม 120 ครั้งต่อนาทีต่อ IP)
- **ถ้ามีข้อความไม่เหมาะสมหลุดขึ้นจอ** ลบทั้งหมดได้ที่ Vercel → Storage → Upstash → Data Browser โดยลบ key `lk:wishes`
- **รูปที่แนบมา** ระบบกรองรูปอัตโนมัติไม่ได้ จึงมีกติกาและทางแก้ดังนี้
  - กระทงที่มีรูปต้องใส่ชื่อเจ้าของเสมอ
  - รูปถูกย่อเหลือประมาณ 5 KB และหายเองใน 7 วัน
  - ถ้ามีรูปไม่เหมาะสมขึ้นจอใหญ่ ให้เปิดจอใหญ่ใหม่ด้วย `/?screen=1&photos=0` เพื่อซ่อนรูปของทุกคนบนจอนั้นทันที
  - จากนั้นลบได้ใน Data Browser: กระทงและรูปอยู่ที่ key `lk:look:<id>` ส่วน id อยู่ในรายการ `lk:wishes`
    (หรือลบ key `lk:wishes` เพื่อล้างทั้งหมด) เครื่องที่เคยโหลดไปแล้วอาจยังเห็นต่อได้อีกไม่เกิน 1 วัน
- **โควต้าฟรี**: คำตอบของ API ถูกเก็บไว้ที่ Vercel 3 วินาที คนเปิดพร้อมกันกี่คนก็ใช้โควต้า Redis เท่าเดิม
  ส่วนจำนวน request ที่นับใน Vercel: จอใหญ่ถามทุก 3 วินาที มือถือและคอมพิวเตอร์ถามทุก 12 วินาที และช้าลงเป็นทุก 30 วินาทีเมื่อไม่มีคนแตะจอนาน 5 นาที

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป

```
npm run dev     # http://localhost:5173  (จอใหญ่: /?screen=1) เก็บข้อมูลในหน่วยความจำ
npm test        # ทดสอบตัวกรอง API และตัวเก็บข้อมูล
```

ถ้าอยากลองจากมือถือที่ต่อ Wi-Fi เดียวกัน ให้รัน `HOST=0.0.0.0 npm run dev` แล้วเปิด `http://<IP เครื่องนี้>:5173`

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html`, `public/app.js` | หน้าใส่ชื่อ และโหมดจอใหญ่ |
| `public/loykrathong-easter-egg.js` | ฉาก 3 มิติ (Three.js) |
| `public/filter.js` | ตัวกรองคำ ใช้ทั้งบนเว็บและบน server |
| `public/workshop.js` | เครื่องมือของโต๊ะทำกระทง (ตัดต้นกล้วย กลีบ ติดของ วาด รูป) ส่วนฉากโต๊ะอยู่ใน `loykrathong-easter-egg.js` |
| `public/design.js` | "สูตรกระทง" ที่ทำเอง และตัวตรวจรูป ใช้ทั้งบนเว็บและบน server |
| `api/wishes.js` | API บน Vercel (GET/POST `/api/wishes`) |
| `api/look.js` | ส่งสูตรกระทงและรูปของแต่ละคน (GET `/api/look?id=`) |
| `api/gallery.js`, `api/heart.js` | ห้องจัดแสดง (GET `/api/gallery`) และหัวใจ (POST `/api/heart`) |
| `public/shelf.js`, `public/gallery.js` | ชั้นวางกระทงของฉัน และหน้าห้องจัดแสดง |
| `lib/store.js` | เก็บข้อมูลใน Upstash Redis |
| `wish-server.js`, `lib/memory-store.js` | เซิร์ฟเวอร์สำหรับรันในเครื่อง |
| `vercel.json` | security headers (CSP และอื่นๆ) และตั้งค่าโฟลเดอร์ |
